## 🎓 Equivalente a Next.js App Router

Aunque no es Next.js, este proyecto incluye:

✅ **Componentes reutilizables** → Similar a `/components`
✅ **Estructura organizada** → Similar a `/app`
✅ **Datos separados** → Similar a `/lib` o `/data`
✅ **Estilos globales** → Similar a `globals.css`
✅ **TypeScript** → Type safety completo
✅ **Routing (opcional)** → React Router ya instalado

### Para migrar a Next.js:
1. Copia todos los componentes a `/app/components`
2. Cambia `export default function` a `export function`
3. Agrega `'use client'` en componentes con estado
4. Los datos pueden quedarse igual
5. Estilos funcionan sin cambios
