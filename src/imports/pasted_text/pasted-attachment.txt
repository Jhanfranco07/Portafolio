Actúa como arquitecto front-end senior y diseñador UX/UI. Genera el diseño y la estructura de una web portfolio profesional en Next.js (App Router) con Tailwind CSS para mi marca personal: "Jhan Freelance".

OBJETIVO:
Crear una landing page moderna, limpia y profesional para mostrar lo que hago como desarrollador freelance, destacar mis proyectos, mi stack tecnológico y facilitar el contacto por WhatsApp o formulario.

ENFOQUE:
No quiero una web estilo agencia grande ni una página inflada con métricas falsas. Quiero una web honesta, moderna y sólida, centrada en:
- lo que construyo
- las tecnologías que uso
- los tipos de soluciones que desarrollo
- algunos proyectos destacados
- contacto claro y directo

ESTILO VISUAL:
- moderno
- limpio
- profesional
- minimalista pero con personalidad
- estética SaaS / portfolio tech
- animaciones suaves y discretas
- responsive
- buena jerarquía visual
- tarjetas elegantes
- íconos y logos tecnológicos bien integrados
- paleta tecnológica en tonos azul, violeta, blanco y grises suaves
- sensación de confianza, claridad y capacidad técnica

STACK:
- Next.js (App Router)
- Tailwind CSS
- Componentes reutilizables
- framer-motion opcional solo para microanimaciones suaves
- Diseño preparado para implementación real
